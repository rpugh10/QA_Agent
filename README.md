# QA Agent
This project is designed to help developers write test cases. The flow will be a developer provides an API specification and business rule. The agent writes tests and runs them against a test application and reports failures/success with evidence.

## Features 
* UI display will contain an area for the user to upload an API specification and business rule
* Backed will send both inputs to Nemotron through Nebius token factory for building and testing the test case.
* The tech stack is currently React for the frontend and Python for the backend.
